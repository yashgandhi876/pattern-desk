# Pattern Desk: live demo

**Site: https://yashgandhi876.github.io/pattern-desk/**

Pattern Desk is a history-based market analysis app for swing trading (1–3 month holds) on NSE stocks, US stocks and crypto, plus Indian IPOs. It tests every price pattern on each asset's own history, checks its own predictions on years it hadn't seen, and shows only what held up.

This repository holds the published website only. It refreshes automatically after each NSE and US market close. The analysis engine is private; the source is available on request.

Not investment advice.
